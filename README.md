# GCI Global 2026 — Home Credit Default Risk



**DataTalks.Club Machine Learning Zoomcamp — Midterm Project**



## 1. Overview



This project develops a machine learning solution to predict the probability of payment difficulties among customers.



The target variable is `TARGET`:

- `0`: No payment difficulties.

- `1`: Payment difficulties.



The competition evaluation metric is **ROC AUC**.



## 2. Dataset



| Dataset | Observations |

|---|---:|

| Training | 171,202 |

| Test | 61,500 |

| Original predictors | 32 |

| Engineered predictors | 84 |



The project uses only the competition-provided `train.csv` and `test.csv` datasets. These files are not included in this repository.



## 3. Methodology



### Exploratory Data Analysis



- Target distribution and class imbalance.

- Missing-value analysis.

- Numerical and categorical feature analysis.

- Default rates across customer groups.

- Adversarial validation.



Adversarial validation achieved a mean AUC of **0.5131**, indicating that training and test datasets are broadly similar.



### Feature Engineering



The original 32 predictors were transformed into 84 features.



Feature groups include:



- Employment anomaly indicators.

- Age and employment duration.

- Financial and affordability ratios.

- External source aggregates.

- Missing-value indicators.

- Bureau request summaries.

- Frequency encoding.



### Validation Strategy



A stratified 5-fold cross-validation strategy was implemented.



An inner validation split (15% of each outer training fold) is used for early stopping. The outer validation fold is never used to determine the number of boosting iterations.



This approach reduces validation leakage.



## 4. Machine Learning Models



Three gradient boosting algorithms were evaluated:



| Model | OOF ROC AUC |

|---|---:|

| CatBoost | 0.758897 |

| LightGBM | 0.756109 |

| XGBoost | 0.754773 |



All models were evaluated using the same cross-validation framework.



## 5. Ensemble Learning



The following strategies were compared:



- Simple average.

- Rank average.

- Nested weighted blend.

- Nested logistic stacking.



Results:



| Strategy | OOF ROC AUC |

|---|---:|

| Nested Weighted Blend | **0.759940** |

| Nested Logistic Stack | 0.759832 |

| Simple Average | 0.759240 |

| Rank Average | 0.759168 |



The Nested Weighted Blend achieved the best OOF ROC AUC.



Its improvement over CatBoost was 0.001046, with a paired bootstrap 95% confidence interval of [0.000572, 0.001466].



## 6. Final Submission



The selected ensemble was refitted using all available out-of-fold predictions and applied to test predictions generated by models trained on the full training dataset.



The final `submission.csv` contains 61,500 predicted probabilities.

## 8. Limitations



- All reported metrics are out-of-fold estimates.

- Test labels are unavailable.

- Leaderboard performance may differ from cross-validation results.

- Hyperparameter optimization was limited to predefined configurations.

- Ensemble selection remains a model-selection procedure.
